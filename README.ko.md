# SculptBox — ZBrush 브러시 관리 & 3D 에셋 관리 도구

**SculptBox 는 macOS 와 Windows 용 ZBrush 브러시 관리 도구입니다. ZBrush 를 실행하지 않고도 브러시 라이브러리(.ZBP / .ZBR / .MNU)를 정리하고 검색하고 태그를 달고 미리 볼 수 있습니다.**

**3D 에셋 관리 도구 — 브러시 라이브러리를 즉시 활용하세요.**

## ⚠️ 첫 설치

macOS에서 **"SculptBox가 손상됨"** 메시지가 뜨면：

```bash
sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app
```

또는 **시스템 설정 → 개인정보 보호 및 보안 → 계속 열기**.

## 🚀 빠른 시작

1. DMG 다운로드 후 Applications에 드래그
2. 차단되면 위 명령어 실행
3. SculptBox 실행
4. Settings → Install로 브릿지 배포
5. ZBrush 재시작

## 자주 묻는 질문

**ZBrush 브러시는 어디에 저장되나요?**
ZBrush 사용자 콘텐츠 폴더(ZStartup / ZBrushData)에 저장됩니다. 정확한 경로는 버전마다 다릅니다.

**브러시가 너무 많아 정리가 안 됩니다.**
SculptBox 에 폴더를 지정하세요. .ZBP / .ZBR / .MNU 를 모두 인덱싱하고 실제 썸네일, 즉시 검색, 태그, 즐겨찾기를 제공합니다.

**LightBox 에서 찾는 대신 이름으로 찾을 수 있나요?**
SculptBox 에서 검색한 뒤 그대로 ZBrush 로 보낼 수 있습니다.

**IMM 브러시, 알파, 매트캡도 지원하나요?**
지원합니다. IMM / 인서트 메시 브러시, 알파, 매트캡, 일반 브러시를 인덱싱합니다.

**ZBrush 업데이트 후 브러시가 사라졌습니다.**
최신 ZBrush 는 사용자 에셋 디렉터리 구조를 변경했습니다. SculptBox 는 지정한 폴더를 스캔하므로 ZBrush 자체 브라우저에 보이지 않는 브러시도 목록화할 수 있습니다.

**ZBrush 없이도 사용할 수 있나요?**
가능합니다. 썸네일은 .ZBP 에서 직접 파싱하므로 ZBrush 실행이나 설치가 필요하지 않습니다.
