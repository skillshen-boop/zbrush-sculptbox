SculptBox — 1.4.0

V1.4.0

2026-09-15
  • 신규: «조각 모드» —— ZBrush 옆에 띄우는 컴팩트한 플로팅 창. 뷰포트를 가리지 않고 브러시를 찾아 보낼 수 있습니다.
  • 메인 창에서 버튼 하나로 서로 전환. 각 창이 자신의 크기·위치·단계를 기억합니다.
  • 신규: 왼쪽 분류 바 —— 모든 애셋 유형을 한 번에. 아이콘 + 첫 글자, 호버 시 전체 이름과 개수.
  • 신규: 카드에서 바로 전송 —— 브러시에 호버 후 Send. 전송되면 버튼이 회색에서 초록으로.
  • 검색·자주 쓰는 키워드·정렬도 플로팅 창에 탑재, 데스크톱판과 동일하게 동작합니다.
  • 변경: 전체 색상 팔레트를 새로 정리. 차분하고 대비가 높은 다크 테마.
  • ZBrush 연결 표시를 신호 아이콘으로 변경. 실행 중에는 초록으로 깜빡입니다.

V1.2.0

2026-09-14
  • 신규: «정보» 페이지 — 제작자, 연락처, WeChat QR 코드.
  • 신규: 업데이트 확인 — 설정 → 업데이트에서 현재 버전 확인, GitHub Releases 조회, 버전별 건너뛰기 가능.
  • 우클릭 메뉴가 이전에 선택한 브러시를 보내던 문제를 수정 (커서 아래 브러시가 대상).
  • ZBrush 상태 표시가 «연결됨 / 오프라인 / 전송 실패» 를 명확히 구분.
  • 패키징된 앱에서 로고가 누락되던 문제를 수정 (assets 미포함).
  • 개인정보: 이전 빌드는 제작자의 로컬 경로와 썸네일 DB를 번들에 포함할 수 있었습니다. 현재는 정리되었습니다.
  • 사이트: 4개 언어 24 페이지로 확장, sitemap / robots 추가.

V1.1.0

2026-09-14
  • 코드 보호 — 8 개 핵심 모듈(ZBP 파싱·Sculpt Bridge·캐시·플러그인 배포)을 네이티브 코드로 컴파일. 번들에 Python 바이트코드가 포함되지 않습니다.
  • 스캔 폴더 중첩으로 인한 대량 브러시 중복 수정 (10,676 → 6,482 개).
  • 즐겨찾기 별이 갱신되지 않던 문제 (짝수 항목이 색이 안 바뀜 / 일괄 삭제 후 잔여).
  • 리스트 위젯을 비울 때 크래시.
  • 백그라운드 작업 중 종료하면 크래시.
  • 패키징된 앱에서 임포트 실패 (28 곳).
  • 백업 파일이 소스 코드를 번들로 유출.
  • 신규: 설정의 «캐시 정리» 버튼 (4 개 언어).
  • 신규: 중첩 스캔 경로 자동 제외.
