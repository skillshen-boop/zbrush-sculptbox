ZBrush のブラシはどこへ？

ZBrush 2026.1 はユーザーアセットの保存方法を作り直しました。アップグレード後にカスタムブラシ・アルファ・マテリアルが見当たらない場合、原因はこれです — 以下が復旧方法です。

SculptBox は macOS / Windows 向けの ZBrush ブラシ管理ツールで、ディスク上に「もともとある場所」をそのまま索引します — ZBrush が再びフォルダ構成を変えても、ブラシは見つかったままです。

2026.1 で実際に変わったこと

ZBrush 2026.1 は、分散していたアセットの保存先を「システムアカウントごとに 1 つのユーザーフォルダ」に置き換えました。以前はインストール先や共有フォルダに置けましたが、現在は 1 か所にまとめる必要があります。

2026.1 より前2026.1 以降
macOS…/ZBrush (バージョン)/ZStartUp/…
Users/Shared/ZBrushData(バージョン)/		/Users/[あなた]/Library/Application Support/Maxon/ZBrush_[HashValue]/
WindowsC:\Program Files\…\ZStartUp\…
Users/Public/Public Documents/		C:\Users\[あなた]\AppData\Roaming\Maxon\ZBrush_[HashValue]\

実務上重要な影響は 2 つです：

  • ZBrush はアプリケーションフォルダに書き込まなくなりました — そのパスは ZBrush 内部からは読み取り専用です。
  • 旧来の共有 ZBrushData(バージョン) フォルダは作成されなくなりました。そこに残したものは読み込まれません。

ブラシの現在の場所

すべてユーザーフォルダ内の ZStartUp の下にあります：

[user assets]/
└── ZStartUp/
    ├── BrushPresets/    ← カスタムブラシ (.ZBP / .ZBR)
    ├── Alphas/
    ├── Materials/
    ├── HotKeys/
    └── …

[user assets]/
├── QuickSaves/
├── LightBox/
└── PluginData/

ブラシを戻す手順

  1. Preferences → Asset Directory → Open Directory を開きます。ZBrush が今まさに使っているフォルダが開くので、推測は不要です。
  2. カスタムファイルを対応する ZStartUp/ サブフォルダへ移動します：ブラシ → BrushPresets、アルファ → Alphas、マテリアル → Materials。
  3. ZBrush を再起動します。Maxon 標準のアセットと一緒に読み込まれます。
  4. 別ドライブ・サーバー・同期フォルダに置きたい場合は Preferences → Asset Directory → Change Location、または環境変数 ZBRUSH_USER_ASSETS_DIR を設定します。Reset to Default で元に戻せます。どちらも ZBrush の再起動が必要です。

なぜ繰り返されるのか

ZBrush のメジャーリリースはほぼ毎回どこかを移動・改名し、そのたびに既に持っていたブラシを探す半日が発生します。フォルダ構成だけで大規模なブラシライブラリを管理するのは無理があります — しかも ZBrush 標準のブラウザには検索もタグも実サムネイルもありません。

SculptBox は別のアプローチを取ります：ブラシフォルダを指定すれば、その場で索引します。.ZBP を直接解析して実サムネイルを表示し、即時検索・タグ・お気に入りを提供し、ワンクリックで ZBrush へ送れます — しかも ZBrush を起動する必要はありません。

つまり次に Maxon がディレクトリを変更しても、ライブラリは失われません。そもそも ZBrush のフォルダ構成に縛られていないからです。

よくある質問

ZBrush 2026.1 でブラシはどこに保存されますか？

ユーザーごとのアセットフォルダです — macOS …/Library/Application Support/Maxon/ZBrush_[HashValue]/ZStartUp/BrushPresets、Windows …\AppData\Roaming\Maxon\ZBrush_[HashValue]\ZStartUp\BrushPresets。

ZBrush のインストールフォルダにブラシを置けますか？

できません。2026.1 以降、ZBrush はアプリケーションルートに書き込まず、共有の ZBrushData(バージョン) フォルダも作成されません。

アップグレード後、古いブラシは自動で読み込まれますか？

新しいユーザーフォルダの ZStartUp にあるものだけです。旧インストール先や共有フォルダに残ったものは表示されません。

ZBrush がなくても SculptBox は使えますか？

使えます — サムネイルは .ZBP から直接解析するため、閲覧に ZBrush の起動もインストールも不要です。
