수천 개 브러시를
창고에 방치하지 마세요

ZBrush 기본 222개를 훨씬 뛰어넘는 브러시를 관리 — 사고, 모으고, 쌓아둔 것 모두 쓸 수 있습니다.
더블클릭하면 ZBrush가 스스로 전환합니다.
3단계 mini 창으로 조각이 한결 자유롭게.

다운로드 바이두 클라우드 (코드: 42by) 비디오

SculptBox는 macOS / Windows용 ZBrush 브러시 관리 도구입니다. 브러시 라이브러리 전체를 ZBrush에 연결합니다: 썸네일 탐색, 밀리초 검색, 더블클릭 자동 전환.

macOS V1.6 · ZBrush 2026+ · GitHub

01 — 브러시 라이브러리

세 글자면 이미 나옵니다.

SculptBox는 라이브러리 전체를 색인하고 모든 썸네일을 네이티브로 분석합니다 — ZBrush를 켜지 않아도 됩니다. 키워드를 입력하면 밀리초 단위로 걸러집니다.

~/ZBrush/ZBrushes 개 색인됨
skin 3건 · 4 ms

02 — 조각 모드

길을 막지 않는 창.

SculptBox의 Mini 창은 ZBrush 위가 아니라 옆에 붙습니다. 3단계 높이, 드래그로 너비 조절, 위치까지 기억합니다 — 조각하는 동안 뷰포트가 가려지지 않습니다.

03 — ZBrush로 전송

브러시를 고르면, 손을 떼기 전에 ZBrush에 있습니다.

우클릭으로 전송. Sculpt Bridge가 브러시를 실시간으로 ZBrush에 넘깁니다 — 하나씩도, 일괄로도, 당신의 라이브러리에서 바로.

자주 묻는 질문

다운로드 전에

SculptBox 는 무료인가요?

네. macOS 와 Windows 모두 무료로 다운로드하고 사용할 수 있습니다.

ZBrush 2025 이전 버전도 지원하나요?

아직 지원하지 않습니다. 그 이전 버전은 구형 Python API를 사용하며 테스트하지 않았습니다 — IPC 채널은 작동할 수 있지만 수동 트리거가 필요합니다.

ZBrush 브러시는 어디에 저장되나요?

ZBrush 2026.1 이후에는 사용자별 에셋 폴더입니다. 정확한 경로는 2026.1 에셋 디렉터리 변경 가이드를 보세요.

브러시가 중복으로 표시됩니다.

V1.0 에서 스캔 폴더 중첩이 원인이었던 결함입니다 (같은 브러시가 상위·하위 폴더 양쪽에 표시). V1.1 은 중첩 경로를 자동 제외하고 파일 경로로 중복을 제거합니다. 계속 보이면 설정에서 다시 스캔하세요.

데이터를 전송하나요?

통신은 선택적 업데이트 확인뿐이며, 보내는 것은 요청 자체뿐입니다. Settings → Update 에서 끌 수 있습니다. 브러시 라이브러리와 파일 이름은 외부로 나가지 않습니다.

지금 시작하세요
