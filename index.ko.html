다운로드 바이두 클라우드 (코드: tayr) 비디오

SculptBox 는 macOS 와 Windows 용 ZBrush 브러시 관리 도구로, ZBrush 를 실행하지 않고도 브러시 라이브러리를 정리하고 검색하고 태그를 달고 미리 볼 수 있습니다.

macOS V1.4 · ZBrush 2026+ · GitHub

01 — 브러시 라이브러리

세 글자면 이미 나옵니다.

SculptBox는 라이브러리 전체를 색인하고 모든 썸네일을 네이티브로 분석합니다 — ZBrush를 켜지 않아도 됩니다. 키워드를 입력하면 밀리초 단위로 걸러집니다.

~/ZBrush/ZBrushes 개 색인됨
skin 3건 · 4 ms

02 — 조각 모드

길을 막지 않는 창.

SculptBox의 Mini 창은 ZBrush 위가 아니라 옆에 붙습니다. 3단계 높이, 드래그로 너비 조절, 위치까지 기억합니다 — 조각하는 동안 뷰포트가 가려지지 않습니다.

03 — ZBrush로 전송

브러시를 고르면, 손을 떼기 전에 ZBrush에 있습니다.

우클릭으로 전송. 로컬 IPC 브리지가 브러시를 실시간으로 ZBrush에 넘깁니다 — 하나씩도, 일괄로도. 300개 제한은 없습니다.

수신됨

기능

브러시 관리

수천 개의 브러시를 밀리초 단위로 응답합니다. 전체 썸네일 미리보기로 파일 이름을 추측할 필요가 없습니다.

조각 모드

ZBrush 옆에 띄우는 컴팩트한 플로팅 창. 뷰포트를 가리지 않고 브러시를 찾아 보냅니다. 3단계 높이, 드래그로 너비 조절, 항상 위에 표시.

썸네일 미리보기

모든 브러시가 실제 썸네일을 표시합니다. 네이티브 ZBP 파싱으로 브러시당 50ms. S/M/L 3단계 크기로 작업 방식에 맞춥니다.

검색과 태그

키워드 입력 즉시 필터링. 10개 자동 태그(Sculpting, Curve, Insert, Utility)와 사용자 태그.

태그 시스템

파일 이름에서 자동 태그 + 수동 추가. 클릭으로 필터링하고 세션 간에도 유지됩니다.

즐겨찾기

자주 쓰는 브러시에 별표를 달아 둡니다. 한 번의 클릭으로 호출하고 항상 목록 맨 앞에 표시됩니다.

S/M/L 그리드

썸네일을 S/M/L 3단계로 전환합니다. 작업 방식에 맞게 보기를 조정하세요.

ZBrush로 전송

우클릭 전송, IPC 브리지로 실시간 반영. 여러 브러시 일괄 전송으로 300개 제한을 넘습니다.

일괄 작업

일괄 전송·내보내기·태그. 진행 상황 추적 내장. 브리지도 원클릭으로 배포합니다.

브리지 상태

상태 점검 패널. ZBrush 상태, 브리지, IPC 준비 상황을 한눈에 확인합니다. 설치 1분.

자주 묻는 질문

다운로드 전에

SculptBox 는 무료인가요?

네. macOS 에서 무료로 다운로드하고 사용할 수 있습니다. Windows 버전도 곧 공개될 예정입니다.

ZBrush 없이도 쓸 수 있나요?

가능합니다. 썸네일은 .ZBP 파일에서 직접 파싱하므로 탐색·검색에 ZBrush 실행이나 설치가 필요하지 않습니다.

브러시 파일을 수정하거나 옮기나요?

아니요. 브러시 폴더를 읽기 전용으로 취급하며, 원본 .ZBP / .ZBR 을 이동·이름 변경·편집하지 않습니다.

데이터를 전송하나요?

통신은 선택적 업데이트 확인뿐이며, 보내는 것은 요청 자체뿐입니다. Settings → Update 에서 끌 수 있습니다. 브러시 라이브러리와 파일 이름은 외부로 나가지 않습니다.

macOS 에서 «손상되어 열 수 없습니다» 라고 나옵니다.

서명되지 않은 앱 경고이며 다운로드 손상이 아닙니다. sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app 를 실행하세요 — 자세한 내용은 다운로드 페이지에 있습니다.
