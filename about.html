About SculptBox

SculptBox is a ZBrush brush manager for macOS and Windows. It indexes your brush library wherever it lives on disk, shows real thumbnails parsed from the .ZBP files, and sends brushes into ZBrush with one click — all without ZBrush needing to be running.

Contact

SculptBox is built by 安迷修de88, an independent developer. It is a third-party plugin for ZBrush, and support for Blender and other 3D software is planned.

sculptbox.net · GitHub · Bilibili · YouTube · Download

ZBrush’s built-in asset browser has no search, no tags and no real thumbnails, and every major release shuffles the folder layout — so a library you spent years building can go missing for an afternoon. SculptBox takes your folders as they are and makes them searchable.
