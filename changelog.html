Release notes

SculptBox — 1.6.0

V1.6.0

2026-09-20
  • New: fully automatic brush switching — double-click a brush and ZBrush switches to it on its own. No need to click the bridge button any more.
  • New: thumbnails for the latest ZBrush brushes (Maxon 2025/2026, 512×512). These previously showed no image at all.
  • Windows build released — same feature set as macOS.
  • In-app guidance (with screenshots) for the macOS permissions that automatic switching needs.
  • Data folder moved to ~/Library/Application Support/SculptBox; existing data migrates automatically.

V1.4.0

2026-09-15
  • New: Sculpt Mode — a compact floating window that sits beside ZBrush, so you can browse and send brushes without covering your viewport.
  • Switch between the main window and Sculpt Mode with one button; each remembers its own size, position and zoom level.
  • New: category sidebar — every asset type one click away, with icon + letter tabs and full names on hover.
  • New: send straight from the card — hover a brush and hit Send; the button turns from grey to green when it goes out.
  • Search, frequent keywords and sorting now live in the floating window too, matching the desktop app.
  • Changed: the whole colour palette was refreshed for a calmer, higher-contrast dark theme.
  • The ZBrush connection indicator is now a signal icon that blinks green while ZBrush is running.

V1.2.0

2026-09-14
  • New: About page — author, contact links and the WeChat QR code.
  • New: Update check — Settings → Update shows your version, queries GitHub Releases, and lets you skip a version.
  • Right-clicking a brush sent the previously selected one; the menu now acts on the brush under the cursor.
  • The ZBrush status block now clearly shows connected / offline / send-failed.
  • The app logo was missing from the packaged build (assets were never bundled).
  • Privacy: earlier builds could ship the author's local paths and thumbnail database inside the app bundle — the bundle is now clean.
  • Site: 24 pages across 4 languages, plus sitemap / robots for search engines.

V1.1.0

2026-09-14
  • Code protection — 8 core modules (ZBP parsing, Sculpt Bridge, caching, plugin deployment) now compile to native code; no Python bytecode ships in the bundle.
  • Nested scan directories produced thousands of duplicate brushes — fixed (10,676 → 6,482 entries).
  • Favorite star did not refresh (even-indexed brushes stayed grey; leftovers after a batch delete).
  • Crash when clearing list widgets.
  • Crash on quit when a background task was still running.
  • Imports failed inside the packaged app (28 sites).
  • Backup files leaked source code into the app bundle.
  • New: Clear Cache button in Settings (4 languages).
  • New: Nested scan paths are filtered automatically.

V1.0.0

2026-05-24
  • First public release.
  • Brush library indexing with real thumbnails parsed from .ZBP files.
  • Instant search, tags, favorites and categories.
  • Send to ZBrush via Sculpt Bridge, including batch send.
  • 4 languages: English, 中文, 日本語, 한국어.
