Install

  1. Download the .dmg and drag SculptBox into your Applications folder.
  2. If macOS refuses to open it, run the command below (see the next section).
  3. Launch SculptBox → Settings → Plugin Status → Install to set up Sculpt Bridge, then restart ZBrush.

“SculptBox is damaged and cannot be opened”

This is not a broken download — the app simply is not code-signed yet. Fix it with one command:

sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app

Or open System Settings → Privacy & Security and click Open Anyway.
