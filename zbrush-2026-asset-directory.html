Where did my ZBrush brushes go?

ZBrush 2026.1 rebuilt how user assets are stored. If your custom brushes, alphas or materials vanished after upgrading, this is why — and here is how to get them back.

SculptBox is a ZBrush brush manager for macOS and Windows that indexes your brush library wherever it already lives on disk — so your brushes stay findable even when ZBrush changes its folder layout again.

What actually changed in 2026.1

ZBrush 2026.1 replaced the old scattered asset locations with a single user folder per system account. Previously custom items could live in the install directory or in shared public folders; now they must all live in one place.

Before 2026.12026.1 and newer
macOS…/ZBrush (Version)/ZStartUp/…
Users/Shared/ZBrushData(Version)/		/Users/[you]/Library/Application Support/Maxon/ZBrush_[HashValue]/
WindowsC:\Program Files\…\ZStartUp\…
Users/Public/Public Documents/		C:\Users\[you]\AppData\Roaming\Maxon\ZBrush_[HashValue]\

Two consequences matter in practice:

  • ZBrush no longer writes files into the application folder — that path is now read-only from inside ZBrush.
  • The old shared ZBrushData(version) folder is no longer created, so anything you left there is not picked up.

Where your brushes are now

Everything lives under a ZStartUp folder inside that user directory:

[user assets]/
└── ZStartUp/
    ├── BrushPresets/    ← custom brushes (.ZBP / .ZBR)
    ├── Alphas/
    ├── Materials/
    ├── HotKeys/
    └── …

[user assets]/
├── QuickSaves/
├── LightBox/
└── PluginData/

How to get your brushes back

  1. Open Preferences → Asset Directory → Open Directory. This reveals the exact folder ZBrush is using right now — no guessing.
  2. Move your custom files into the matching ZStartUp/ subfolder: brushes → BrushPresets, alphas → Alphas, materials → Materials.
  3. Restart ZBrush. They load alongside Maxon's own assets at startup.
  4. Want the folder on another drive, a server or a synced directory? Use Preferences → Asset Directory → Change Location, or set the environment variable ZBRUSH_USER_ASSETS_DIR. Reset to Default reverts it — restart ZBrush afterwards either way.

Why this keeps happening

Every major ZBrush release has moved or renamed something, and each move costs you an afternoon of hunting for brushes you already had. Managing a large brush library by folder shape alone does not scale — and ZBrush's own browser gives you no search, no tags and no real thumbnails.

SculptBox takes a different approach: point it at your brush folders and it indexes them where they are. It parses .ZBP files directly to show real thumbnails, gives you instant search, tags and favorites, and can send a brush straight into ZBrush — and it does all of that without ZBrush needing to be running.

That means the next time Maxon reshuffles the directory, your library does not go missing: it was never tied to ZBrush's folder layout in the first place.

FAQ

Where are ZBrush brushes stored in 2026.1?

In the per-user asset folder — macOS …/Library/Application Support/Maxon/ZBrush_[HashValue]/ZStartUp/BrushPresets, Windows …\AppData\Roaming\Maxon\ZBrush_[HashValue]\ZStartUp\BrushPresets.

Can I still put brushes in the ZBrush install folder?

No. From 2026.1 ZBrush will not write to the application root, and the shared ZBrushData(version) folder is no longer created.

Will my old brushes load automatically after upgrading?

Only if they sit in the new per-user ZStartUp location. Anything left in the old install or shared folders will not appear.

Does SculptBox work without ZBrush installed?

Yes — thumbnails are parsed natively from the .ZBP files, so ZBrush does not need to be running, or even installed, to browse your library.
