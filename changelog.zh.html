SculptBox — 1.4.0

V1.4.0

2026-09-15
  • 新增：「雕刻模式」—— 一个紧凑的悬浮窗，挂在 ZBrush 旁边，浏览和发送笔刷时不遮挡视口。
  • 主窗口顶栏一个按钮即可与雕刻模式互相切换；两个窗口各自记住自己的尺寸、位置和档位。
  • 新增：左侧分类栏 —— 所有资产类型一键直达，图标 + 首字母，悬停显示全名与数量。
  • 新增：卡片上直接发送 —— 悬停笔刷点 Send，发出后按钮由灰变绿。
  • 搜索、常用词、排序也搬进了悬浮窗，与桌面端行为一致。
  • 改版：整套配色刷新，暗色主题更沉稳、对比更清晰。
  • ZBrush 连接指示改成信号图标，运行时绿色闪烁。

V1.2.0

2026-09-14
  • 新增：「关于」页 —— 作者、联系方式与微信二维码。
  • 新增：更新检查 —— 设置 → 更新 可查看当前版本、查询 GitHub Releases，并可按版本跳过。
  • 右键菜单会误发上一次选中的笔刷，现在改为作用于光标下的笔刷。
  • ZBrush 状态块现在能清晰区分「已连接 / 离线 / 发送失败」三种状态。
  • 打包后应用内缺失 logo（assets 从未被打进包）。
  • 隐私：此前的构建可能把作者本地路径与缩略图数据库打进安装包，现在包内已清理干净。
  • 官网：扩至 4 语言 24 个页面，并补齐 sitemap / robots。

V1.1.0

2026-09-14
  • 代码保护 —— 8 个核心模块（ZBP 解析 / IPC / 缓存 / 插件部署）编译为原生代码；包内不含 Python 字节码。
  • 扫描目录嵌套导致大量重复笔刷 —— 已修复（10,676 → 6,482 条）。
  • 收藏星标不刷新（偶数项不变黄；批量删除后残留）。
  • 清空列表控件时崩溃。
  • 后台任务仍在运行时退出会崩溃。
  • 打包后应用内导入失败（28 处）。
  • 备份文件把源码带进了应用包。
  • 新增：设置里的「清理缓存」按钮（4 语言）。
  • 新增：嵌套扫描路径自动剔除。

V1.0.0

2026-05-24
  • 首个公开版本。
  • 笔刷库索引，缩略图从 .ZBP 文件原生解析。
  • 即时搜索、标签、收藏与分类。
  • 通过 IPC 桥接发送笔刷到 ZBrush，支持批量发送。
  • 4 语言：English / 中文 / 日本語 / 한국어。
