インストール手順

  1. .dmg をダウンロードし、SculptBox をアプリケーションフォルダへドラッグします。
  2. macOS が開けない場合は、以下のコマンドを実行します（次の節を参照）。
  3. SculptBox を起動 → Settings → Plugin Status → Install で ZBrush ブリッジを配置し、ZBrush を再起動します。

「SculptBox は壊れているため開けません」

ダウンロードが壊れているわけではありません — まだコード署名をしていないだけです。1 つのコマンドで解決します：

sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app

または システム設定 → プライバシーとセキュリティ で このまま開く をクリックします。
