SculptBox 是一款面向 macOS 与 Windows 的 ZBrush 笔刷管理工具，让 3D 艺术家无需打开 ZBrush 即可整理、搜索、打标签和预览自己的笔刷库。

macOS V1.1 · ZBrush 2026+ · GitHub

功能

笔刷管理

万级笔刷库，毫秒级响应。完整缩略图预览，不用再靠文件名猜。

缩略图预览

每个笔刷实时显示缩略图。原生 ZBP 解析，50ms 一个。S/M/L 三级尺寸。

搜索与标签

输入关键词即时过滤。10 个自动标签 + 自定义标签，笔刷自动归类。

标签系统

自动检测标签 + 手动添加。点击勾选过滤，跨会话持久化。

收藏夹

常用笔刷点星标自动收藏。永远在最前面，一键切换。

三级缩放

S/M/L 三级缩略图尺寸，适应不同的浏览习惯。

发送到 ZBrush

右键发送，IPC 桥接实时加载。批量发送多支笔刷，打破 ZBrush 300 上限。

批量操作

批量发送、批量导出、批量标记。内置进度追踪，一键部署桥接。

桥接状态

健康检测面板，ZBrush 状态、桥接、IPC 一眼看清。1 分钟完成安装。

多语言

中文 · English · 日本語 · 한국어，随时切换。

设置与关于

完整设置面板：扫描目录、ZBrush 路径、缓存、语言、更新、关于。
