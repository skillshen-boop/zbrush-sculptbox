SculptBox 是一款面向 macOS 与 Windows 的 ZBrush 笔刷管理工具，让 3D 艺术家无需打开 ZBrush 即可整理、搜索、打标签和预览自己的笔刷库。

macOS V1.4 · ZBrush 2026+ · GitHub

01 — 笔刷库

打三个字母，它已经在眼前。

SculptBox 索引整个笔刷库，原生解析每一张缩略图 — 连 ZBrush 都不用开着。输入关键词，毫秒级过滤。

02 — 雕刻模式

一个不挡路的窗口。

SculptBox 的 Mini 窗挂在 ZBrush 旁边，而不是盖在它上面。三档高度、拖拽调宽、位置记忆 — 雕刻过程中视口永远不会被挡住。

03 — 发送到 ZBrush

选一支笔刷，松手时它已经在 ZBrush 里。

右键发送。Sculpt Bridge 把笔刷实时交给 ZBrush — 可以单支，也可以整批。没有 300 支的上限。

常见问题

下载前你可能想知道

SculptBox 免费吗？

免费。macOS 上可免费下载与使用；Windows 版本即将完成并发布。

没装 ZBrush 能用吗？

可以。缩略图是从 .ZBP 文件原生解析的，所以浏览和搜索笔刷库不需要 ZBrush 运行，甚至不需要安装。

SculptBox 会修改或移动我的笔刷文件吗？

不会。SculptBox 把你的笔刷目录视为只读，从不移动、改名或修改原始的 .ZBP / .ZBR 文件。

SculptBox 会上传数据吗？

唯一的网络访问是可选的更新检查，且只发送请求本身。可在 设置 → 更新 里关闭。你的笔刷库和文件名不会离开本机。

macOS 提示应用已损坏，打不开。

那是未签名应用的提示，不是文件损坏。执行 sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app 即可 —— 详见下载页。
