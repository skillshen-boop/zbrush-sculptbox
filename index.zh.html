SculptBox 是一款面向 macOS 与 Windows 的 ZBrush 笔刷管理工具。把整个笔刷库接进 ZBrush：缩略图浏览、毫秒级搜索、双击即自动切换。

macOS V1.6 · ZBrush 2026+ · GitHub

你正在经历的这 9 件事，是不是你的日常？

01收藏了 10 年、几十 GB 的笔刷，散在好几块硬盘和文件夹里 — 找一支要翻半小时。
02ZBrush 只认它自己那个文件夹。你买的、攒的外部笔刷库，它根本看不见。
03想用？只能一支一支 Load Brush 手动导。几百支导到手酸。
04导进去还不行：条目一多，ZBrush 会把多余的折叠隐藏起来（官方文档原话，R 按钮）。
05在 Finder / 资源管理器里，笔刷文件就是一堆没图标的文件 — 只能盯着文件名猜。
06做个复杂项目要用几十支笔刷 — 就在 ZBrush 和文件夹之间来回切窗口，一天切几百次。
07ZBrush 一升级、一重装，你辛苦整理的全归零。2026.1 改资产目录时就有人中招。
08最顺手的那十几支，每次还得重新找一遍 — 没有收藏夹，也没有「最近用过」。
09结果：几十 GB 在硬盘里吃灰，你翻来覆去只用那十几支。

这 9 件事，SculptBox 一次全解决。不用手动加载，不用来回切窗口。

02 — 雕刻模式

一个不挡路的窗口。

SculptBox 的 Mini 窗挂在 ZBrush 旁边，而不是盖在它上面。三档高度、拖拽调宽、位置记忆 — 雕刻过程中视口永远不会被挡住。

03 — 发送到 ZBrush

常见问题

下载前你可能想知道

SculptBox 免费吗？

免费。macOS 与 Windows 上均可免费下载使用。

支持 ZBrush 2025 或更早的版本吗？

暂不支持。那些版本用的是旧的 Python 接口，我们未做测试 —— IPC 通道可能仍可用，但需要手动触发。

我的 ZBrush 笔刷存在哪里？

在 ZBrush 2026.1 及以后，它们位于每个用户自己的资产目录里。具体路径见 ZBrush 2026.1 目录变更指南。

笔刷重复显示了两次？

这是 V1.0 因扫描目录嵌套导致的缺陷（同一个笔刷同时出现在父目录和子目录下）。V1.1 会自动过滤嵌套路径并按文件路径去重。如果仍有重复，请在设置里重新扫描。

SculptBox 会上传数据吗？

唯一的网络访问是可选的更新检查，且只发送请求本身。可在 设置 → 更新 里关闭。你的笔刷库和文件名不会离开本机。
