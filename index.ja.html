集めたブラシは数千本
実際に使うのは何本？

ZBrush の標準は 222 本 — 苦労して集めたブラシを、ハードディスクで眠らせないで。
ダブルクリックすれば、ZBrush が自動で切り替え。
3 段階の mini ウィンドウで、彫刻がもっと自由に。

ダウンロード 百度網盤 (コード: 42by) ビデオ

SculptBox は macOS / Windows 向けの ZBrush ブラシ管理ツールです。ブラシライブラリ全体を ZBrush につなぎます：サムネイル閲覧、ミリ秒検索、ダブルクリックで自動切り替え。

macOS V1.6 · ZBrush 2026+ · GitHub

01 — ブラシライブラリ

三文字で、もう出ている。

SculptBox はライブラリ全体を索引し、すべてのサムネイルをネイティブに解析します — ZBrush を起動していなくても。キーワードを入力すればミリ秒で絞り込めます。

~/ZBrush/ZBrushes 本を索引済み
skin 3 件 · 4 ms

02 — 彫刻モード

邪魔をしないウィンドウ。

SculptBox の Mini ウィンドウは ZBrush の「上」ではなく「隣」に置かれます。3 段階の高さ、ドラッグで幅変更、位置も記憶 — 彫刻中にビューポートが覆われることはありません。

03 — ZBrush へ送信

ブラシを選ぶ。指を離す前に ZBrush にある。

右クリックで送信。Sculpt Bridge がブラシをリアルタイムで ZBrush に渡します — 1 本でも一括でも、あなた自身のライブラリから。

よくある質問

ダウンロードの前に

SculptBox は無料ですか？

はい。macOS / Windows どちらでも無料でダウンロード・利用できます。

ZBrush 2025 以前は対応していますか？

未対応です。それ以前は古い Python API を使用しており、検証していません — IPC チャンネルは動作する可能性がありますが、手動トリガーが必要です。

ZBrush のブラシはどこに保存されますか？

ZBrush 2026.1 以降はユーザーごとのアセットフォルダです。正確なパスは2026.1 アセットディレクトリ変更ガイドをご覧ください。

ブラシが重複して表示されます。

V1.0 でスキャンフォルダの入れ子が原因だった不具合です（同じブラシが親フォルダと子フォルダの両方に出る）。V1.1 では入れ子パスを自動で除外し、ファイルパスで重複排除します。改善しない場合は設定から再スキャンしてください。

データを送信しますか？

通信は任意のアップデート確認のみで、送信するのはリクエスト自体だけです。Settings → Update でオフにできます。ブラシライブラリやファイル名が外部に出ることはありません。
