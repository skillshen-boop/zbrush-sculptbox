SculptBox is a ZBrush brush manager for macOS and Windows. It plugs your whole brush library into ZBrush: thumbnail browsing, millisecond search, and double-click auto-switch.

macOS V1.6 · ZBrush 2026+ · GitHub

Sound familiar?9 problems you hit every day in ZBrush.

01Ten years of collected brushes — dozens of GB — scattered across several drives and folders. Finding one takes half an hour.
02ZBrush only reads its own folder. The libraries you bought and hoarded? It can't see them at all.
03To use one you load it by hand, one at a time, with Load Brush. A few hundred and your wrist gives up.
04And even then it fights back: once the palette gets big, ZBrush hides the extras behind the R button (their own documentation says so).
05In Finder or Explorer a brush file is just a nameless file. No thumbnail, no preview — you guess from the filename.
06A complex piece needs dozens of brushes — so you flip between ZBrush and a folder window, hundreds of times a day.
07Update or reinstall ZBrush and your carefully arranged setup is gone. The 2026.1 asset-folder change wiped it for plenty of people.
08Your dozen go-to brushes get hunted down again every single time — no favourites, no recents.
09So dozens of GB sit on a drive, and you cycle through the same dozen brushes.

01 — Brush library

Type three letters. It's already there.

SculptBox indexes the whole library and reads every thumbnail natively — ZBrush doesn't even need to be running. Type a keyword and it filters in milliseconds.

~/ZBrush/ZBrushes brushes indexed
skin 3 hits · 4 ms

02 — Sculpt Mode

The window that stays out of the way.

SculptBox's Mini window sits beside ZBrush instead of on top of it. Three heights, drag to resize, and it remembers where you put it — so your viewport never gets covered mid-sculpt.

03 — Send to ZBrush

Pick a brush. It's in ZBrush before you let go.

Right-click and send. Sculpt Bridge hands the brush to ZBrush in real time — one brush or a whole batch, straight from your own library.

Common questions

Before you download

Is SculptBox free?

Yes — free to download and use on macOS and Windows.

Does it support ZBrush 2025 or earlier?

Not yet. Those versions use an older Python API that we have not tested — the IPC channel may still work, but requires manual triggering.

Where are my ZBrush brushes stored?

In ZBrush 2026.1 and newer they live in a per-user asset folder. See our guide to the 2026.1 asset directory change for the exact paths on macOS and Windows.

My brushes are showing twice / duplicated.

This was a V1.0 bug caused by nested scan directories (the same brush appearing under both a parent and a child folder). V1.1 filters nested paths automatically and de-duplicates by file path. If you still see duplicates, re-scan your library from Settings.

Does SculptBox send any data?

The only network access is an optional update check, and it sends nothing but the request itself. You can turn it off in Settings → Update. Your brush library and file names never leave your machine.
