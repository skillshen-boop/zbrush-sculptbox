SculptBox is a ZBrush brush manager for macOS and Windows that lets 3D artists organize, search, tag and preview their ZBrush brush library outside of ZBrush.

macOS V1.6 · ZBrush 2026+ · GitHub

01 — Brush library

Type three letters. It's already there.

SculptBox indexes the whole library and reads every thumbnail natively — ZBrush doesn't even need to be running. Type a keyword and it filters in milliseconds.

~/ZBrush/ZBrushes brushes indexed
skin 3 hits · 4 ms

02 — Sculpt Mode

The window that stays out of the way.

SculptBox's Mini window sits beside ZBrush instead of on top of it. Three heights, drag to resize, and it remembers where you put it — so your viewport never gets covered mid-sculpt.

03 — Send to ZBrush

Pick a brush. It's in ZBrush before you let go.

Right-click and send. Sculpt Bridge hands the brush to ZBrush in real time — one at a time or a whole batch. No 300-brush ceiling.

Common questions

Before you download

Is SculptBox free?

Yes — free to download and use on macOS and Windows.

Does it support ZBrush 2025 or earlier?

Not yet. Those versions use an older Python API that we have not tested — the IPC channel may still work, but requires manual triggering.

Where are my ZBrush brushes stored?

In ZBrush 2026.1 and newer they live in a per-user asset folder. See our guide to the 2026.1 asset directory change for the exact paths on macOS and Windows.

My brushes are showing twice / duplicated.

This was a V1.0 bug caused by nested scan directories (the same brush appearing under both a parent and a child folder). V1.1 filters nested paths automatically and de-duplicates by file path. If you still see duplicates, re-scan your library from Settings.

Does SculptBox send any data?

The only network access is an optional update check, and it sends nothing but the request itself. You can turn it off in Settings → Update. Your brush library and file names never leave your machine.
