SculptBox is a ZBrush brush manager for macOS and Windows that lets 3D artists organize, search, tag and preview their ZBrush brush library outside of ZBrush.

macOS V1.4 · ZBrush 2026+ · GitHub

01 — Brush library

Type three letters. It's already there.

SculptBox indexes the whole library and reads every thumbnail natively — ZBrush doesn't even need to be running. Type a keyword and it filters in milliseconds.

~/ZBrush/ZBrushes brushes indexed
skin 3 hits · 4 ms

02 — Sculpt Mode

The window that stays out of the way.

SculptBox's Mini window sits beside ZBrush instead of on top of it. Three heights, drag to resize, and it remembers where you put it — so your viewport never gets covered mid-sculpt.

03 — Send to ZBrush

Pick a brush. It's in ZBrush before you let go.

Right-click and send. A local IPC bridge hands the brush to ZBrush in real time — one at a time or a whole batch. No 300-brush ceiling.

Features

Brush Management

Thousands of brushes, millisecond response. Full thumbnail preview — no more guessing from file names.

Sculpt Mode

A compact floating window that sits beside ZBrush. Browse, search and send brushes without covering your viewport. Three heights, drag to resize, always on top.

Thumbnail Preview

Every brush shows its real thumbnail. Native ZBP parsing, 50ms per brush. S/M/L sizes for any workflow.

Search & Tags

Instant keyword search. 10 auto-tags (Sculpting, Curve, Insert, Utility) plus custom tags.

Tag System

Auto-tags from file names + manual tagging. Click to filter. Persists across sessions.

Favorites

Star your most-used brushes. Access them in one click. Always at the top of your library.

S/M/L Grid Sizes

Switch between Small, Medium, and Large thumbnail sizes. Adapt the view to your workflow.

Send to ZBrush

Right-click send, real-time IPC bridge. Batch send multiple brushes. No more 300-brush limit.

Batch Operations

Batch send, batch export, batch tag. Built-in progress tracking. One-click bridge deployment.

Plugin Status

Health check dashboard. ZBrush status, bridge, IPC readiness at a glance. Install in 1 minute.

Common questions

Before you download

Is SculptBox free?

Yes — free to download and use on macOS. The Windows build is nearly ready and will be released soon.

Does SculptBox work without ZBrush installed?

Yes. Thumbnails are parsed natively from the .ZBP files, so ZBrush does not need to be running — or installed — to browse and search your brush library.

Does SculptBox modify or move my brush files?

No. SculptBox treats your brush folders as read-only. It never moves, renames or edits the original .ZBP / .ZBR files.

Does SculptBox send any data?

The only network access is an optional update check, and it sends nothing but the request itself. You can turn it off in Settings → Update. Your brush library and file names never leave your machine.

macOS says the app is damaged and cannot be opened.

That is the unsigned-app warning, not a corrupt download. Run sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app — see the download page for details.
