SculptBox › ZBrush 2026.1 에셋 디렉터리 변경

내 ZBrush 브러시는 어디로 갔나?

ZBrush 2026.1 은 사용자 에셋 저장 방식을 새로 만들었습니다. 업그레이드 후 커스텀 브러시, 알파, 매트리얼이 사라졌다면 이유는 이것입니다 — 아래는 되찾는 방법입니다.

SculptBox 는 macOS 와 Windows 용 ZBrush 브러시 관리 도구로, 디스크에 «이미 있는 위치» 를 그대로 인덱싱합니다 — ZBrush 가 폴더 구조를 또 바꿔도 브러시는 계속 찾을 수 있습니다.

2026.1 에서 실제로 바뀐 것

ZBrush 2026.1 은 흩어져 있던 에셋 위치를 «시스템 계정당 하나의 사용자 폴더» 로 교체했습니다. 예전에는 설치 폴더나 공용 폴더에 둘 수 있었지만, 이제는 한곳에 모아야 합니다.

2026.1 이전2026.1 이후
macOS…/ZBrush (버전)/ZStartUp/…
Users/Shared/ZBrushData(버전)/		/Users/[사용자]/Library/Application Support/Maxon/ZBrush_[HashValue]/
WindowsC:\Program Files\…\ZStartUp\…
Users/Public/Public Documents/		C:\Users\[사용자]\AppData\Roaming\Maxon\ZBrush_[HashValue]\

실무에서 중요한 영향은 두 가지입니다:

  • ZBrush 가 애플리케이션 폴더에 더 이상 파일을 쓰지 않습니다 — 해당 경로는 이제 내부에서 읽기 전용입니다.
  • 예전 공용 ZBrushData(버전) 폴더가 더 이상 생성되지 않습니다. 거기 남긴 것은 읽히지 않습니다.

브러시가 지금 있는 곳

모든 것이 사용자 폴더 안 ZStartUp 아래에 있습니다:

[user assets]/
└── ZStartUp/
    ├── BrushPresets/    ← 커스텀 브러시 (.ZBP / .ZBR)
    ├── Alphas/
    ├── Materials/
    ├── HotKeys/
    └── …

[user assets]/
├── QuickSaves/
├── LightBox/
└── PluginData/

브러시를 되찾는 방법

  1. Preferences → Asset Directory → Open Directory 를 엽니다. ZBrush 가 지금 쓰는 폴더가 바로 열리므로 추측할 필요가 없습니다.
  2. 커스텀 파일을 해당 ZStartUp/ 하위 폴더로 옮깁니다: 브러시 → BrushPresets, 알파 → Alphas, 매트리얼 → Materials.
  3. ZBrush 를 재시작합니다. Maxon 기본 에셋과 함께 로드됩니다.
  4. 다른 드라이브, 서버, 동기화 폴더에 두고 싶다면 Preferences → Asset Directory → Change Location 또는 환경변수 ZBRUSH_USER_ASSETS_DIR 를 사용합니다. Reset to Default 로 되돌릴 수 있으며, 어느 쪽이든 ZBrush 재시작이 필요합니다.

왜 계속 반복되는가

ZBrush 메이저 릴리스는 거의 매번 무언가를 옮기거나 이름을 바꾸고, 그때마다 이미 갖고 있던 브러시를 찾느라 반나절이 사라집니다. 폴더 구조만으로 거대한 브러시 라이브러리를 관리하는 것은 한계가 있습니다 — 게다가 ZBrush 기본 브라우저에는 검색도, 태그도, 실제 썸네일도 없습니다.

SculptBox 는 다른 방식을 씁니다: 브러시 폴더를 지정하면 그 자리에서 인덱싱합니다. .ZBP 를 직접 파싱해 실제 썸네일을 보여주고, 즉시 검색 · 태그 · 즐겨찾기를 제공하며, 클릭 한 번으로 ZBrush 로 보냅니다 — ZBrush 를 실행할 필요도 없습니다.

즉 다음에 Maxon 이 디렉터리를 또 바꿔도 라이브러리는 사라지지 않습니다. 애초에 ZBrush 폴더 구조에 묶여 있지 않기 때문입니다.

자주 묻는 질문

ZBrush 2026.1 에서 브러시는 어디에 저장되나요?

사용자별 에셋 폴더입니다 — macOS …/Library/Application Support/Maxon/ZBrush_[HashValue]/ZStartUp/BrushPresets, Windows …\AppData\Roaming\Maxon\ZBrush_[HashValue]\ZStartUp\BrushPresets.

ZBrush 설치 폴더에 브러시를 둘 수 있나요?

없습니다. 2026.1 부터 ZBrush 는 애플리케이션 루트에 쓰지 않으며, 공용 ZBrushData(버전) 폴더도 생성되지 않습니다.

업그레이드 후 기존 브러시가 자동으로 로드되나요?

새 사용자 폴더의 ZStartUp 에 있는 것만 로드됩니다. 예전 설치 폴더나 공용 폴더에 남은 것은 나타나지 않습니다.

ZBrush 없이도 SculptBox 를 쓸 수 있나요?

가능합니다 — 썸네일은 .ZBP 에서 직접 파싱하므로 ZBrush 실행이나 설치가 필요하지 않습니다.
