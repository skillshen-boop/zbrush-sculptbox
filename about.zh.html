关于 SculptBox

SculptBox 是一款面向 macOS 与 Windows 的 ZBrush 笔刷管理工具。它索引你磁盘上笔刷「本来就在的地方」，显示从 .ZBP 文件解析出的真实缩略图，一键把笔刷送进 ZBrush —— 而且全程不需要 ZBrush 在运行。

联系作者

SculptBox 由独立开发者 安迷修de88 开发，是 ZBrush 的第三方插件，后续还会增加 Blender 等软件的支持。

sculptbox.net · GitHub · Bilibili · YouTube · Download

ZBrush 自带的资产浏览器没有搜索、没有标签、也没有真正的缩略图，而且几乎每个大版本都会挪动目录结构 —— 于是你攒了很多年的笔刷库，可能因为一次升级就「消失」一下午。SculptBox 的做法是：你的目录不动，直接让它变得可搜索。
