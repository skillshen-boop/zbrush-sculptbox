SculptBox › ZBrush 2026.1 资产目录变更

我的 ZBrush 笔刷去哪了？

ZBrush 2026.1 重建了用户资产的存放方式。如果你升级后发现自定义笔刷、Alpha 或材质不见了，原因就在这里 —— 下面是怎么找回它们。

SculptBox 是一款面向 macOS 与 Windows 的 ZBrush 笔刷管理工具，它索引的是你磁盘上笔刷「本来就在的地方」 —— 所以就算 ZBrush 再改一次目录结构，你的笔刷依然找得到。

2026.1 到底改了什么

ZBrush 2026.1 把原来分散的资产位置换成了「每个系统账户一个用户目录」。以前自定义内容可以放在安装目录或公共共享目录，现在必须全部放在一个地方。

2026.1 之前2026.1 及以后
macOS…/ZBrush (版本)/ZStartUp/…
Users/Shared/ZBrushData(版本)/		/Users/[你]/Library/Application Support/Maxon/ZBrush_[HashValue]/
WindowsC:\Program Files\…\ZStartUp\…
Users/Public/Public Documents/		C:\Users\[你]\AppData\Roaming\Maxon\ZBrush_[HashValue]\

实际影响有两条：

  • ZBrush 不再往应用目录写文件了 —— 那个路径从 ZBrush 内部现在是只读的。
  • 旧的公共 ZBrushData(版本) 目录不再创建，所以留在那儿的笔刷不会被读取。

你的笔刷现在在哪

所有东西都在那个用户目录下的 ZStartUp 里：

[user assets]/
└── ZStartUp/
    ├── BrushPresets/    ← 自定义笔刷 (.ZBP / .ZBR)
    ├── Alphas/
    ├── Materials/
    ├── HotKeys/
    └── …

[user assets]/
├── QuickSaves/
├── LightBox/
└── PluginData/

怎么把笔刷找回来

  1. 打开 Preferences → Asset Directory → Open Directory。这会直接打开 ZBrush 当前正在用的那个目录，不用猜。
  2. 把自定义文件放进对应的 ZStartUp/ 子目录：笔刷 → BrushPresets，Alpha → Alphas，材质 → Materials。
  3. 重启 ZBrush。它们会和 Maxon 自带资产一起在启动时加载。
  4. 想把目录放到别的盘、服务器或同步目录？用 Preferences → Asset Directory → Change Location，或设置环境变量 ZBRUSH_USER_ASSETS_DIR。Reset to Default 可以还原 —— 两种方式改完都要重启 ZBrush。

为什么会一再发生

几乎每个 ZBrush 大版本都会挪动或改名一些东西，而每次挪动都要花你一个下午去找本来就已经有的笔刷。仅靠目录结构管理庞大的笔刷库是撑不住的 —— 何况 ZBrush 自带的浏览器没有搜索、没有标签、也没有真正的缩略图。

SculptBox 换了个思路：指向你的笔刷目录，它就地索引。它直接解析 .ZBP 文件显示真实缩略图，提供即时搜索、标签和收藏，还能一键把笔刷送进 ZBrush —— 而且做这些都不需要 ZBrush 在运行。

也就是说，下次 Maxon 再动目录结构时，你的库不会「消失」：它从一开始就没和 ZBrush 的目录绑在一起。

常见问题

ZBrush 2026.1 的笔刷存在哪里？

在每个用户自己的资产目录里 —— macOS …/Library/Application Support/Maxon/ZBrush_[HashValue]/ZStartUp/BrushPresets，Windows …\AppData\Roaming\Maxon\ZBrush_[HashValue]\ZStartUp\BrushPresets。

还能把笔刷放在 ZBrush 安装目录里吗？

不能。从 2026.1 起 ZBrush 不再往应用根目录写文件，旧的公共 ZBrushData(版本) 目录也不再创建。

升级后旧笔刷会自动加载吗？

只有当它们在新的用户目录 ZStartUp 下才会。还留在旧安装目录或公共目录里的不会出现。

没装 ZBrush 能用 SculptBox 吗？

可以 —— 缩略图是从 .ZBP 文件原生解析的，浏览笔刷库不需要 ZBrush 运行，甚至不需要安装。
