Frequently asked questions

Is SculptBox free?

Yes — free to download and use on macOS. The Windows build is nearly ready and will be released soon.

Which ZBrush versions are supported?

Browsing your library works independently of ZBrush. The Send to ZBrush feature requires ZBrush 2026 or later, because it uses the ZBrush Python bridge.

Does SculptBox work without ZBrush installed?

Yes. Thumbnails are parsed natively from the .ZBP files, so ZBrush does not need to be running — or installed — to browse and search your brush library.

Where are my ZBrush brushes stored?

In ZBrush 2026.1 and newer they live in a per-user asset folder. See our guide to the 2026.1 asset directory change for the exact paths on macOS and Windows.

My brushes are showing twice / duplicated.

This was a V1.0 bug caused by nested scan directories (the same brush appearing under both a parent and a child folder). V1.1 filters nested paths automatically and de-duplicates by file path. If you still see duplicates, re-scan your library from Settings.

Does SculptBox modify or move my brush files?

No. SculptBox treats your brush folders as read-only. It never moves, renames or edits the original .ZBP / .ZBR files.

Does SculptBox send any data?

The only network access is an optional update check, and it sends nothing but the request itself. You can turn it off in Settings → Update. Your brush library and file names never leave your machine.

Does it handle alphas, materials and textures too?

Yes. SculptBox indexes brushes, alphas, materials and textures, and gives each type its own category.

macOS says the app is damaged and cannot be opened.

That is the unsigned-app warning, not a corrupt download. Run sudo xattr -rd com.apple.quarantine /Applications/SculptBox.app — see the download page for details.

How do I uninstall SculptBox?

Delete the app from Applications, then remove its cache folder (macOS: ~/Library/Application Support/ZBrush4/SculptBox). If you deployed the ZBrush bridge, remove it from Settings → Plugin first.
